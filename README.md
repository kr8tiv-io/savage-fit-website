# Savage Fit · wethesavage.com

> Online fitness coaching for an IFBB Pro. Client build by [kr8tiv.io](https://kr8tiv.io).

[![Live](https://img.shields.io/badge/live-wethesavage.com-FF00AA?style=for-the-badge)](https://wethesavage.com)

A multi-page static site for an IFBB Pro bodybuilder running online coaching, training programs, supplements, and challenge cohorts. Built around long-form sales pages, lead capture, and conversion-optimised product flows.

## What's in here

```
savage-fit-website/
├── index.html              # main landing page (~440KB hand-rolled HTML)
├── animation-script.js     # scroll + reveal animations
├── favicon.ico
├── .nojekyll               # tell GitHub Pages not to run Jekyll
├── assets/                 # imagery, video, brand assets
├── challenges/             # challenge cohort landing pages
├── products/               # supplement product pages
├── subscription/           # coaching subscription tier pages
├── spring-aesthetic/       # seasonal program landing
└── training/               # training program landing pages
```

## Stack

- **HTML / CSS / vanilla JS** — no framework. Static, fast, indexable.
- **GitHub Pages-friendly** — `.nojekyll` + raw HTML, deploys anywhere.

## Build approach

Long-form sales-letter aesthetic — think classic direct response, modernised. Heavy on hero photography, social proof, big calls-to-action, and conversion-optimised landing flows for paid traffic.
